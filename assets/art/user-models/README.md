# 使用者提供的 GLB 模型

將 GLB 檔案直接放在此資料夾，中文檔名也可以，例如「玫瑰.glb」、「月亮.glb」。

上傳後先檢查造型、尺寸、材質與效能，再整合場景；接收區不會自動覆蓋現有模型。
有來源網址或授權文件可以一起放入，未提供時標記為「使用者提供，來源授權未確認」。

四座場景目前已接入：`同頻星球.glb`、`月光書原.glb`、`玫瑰花園.glb`、`微風森林.glb`。網站使用 `public/models/user-worlds` 的輕量副本；這裡保留上傳原檔。

配置與驗證見專案根目錄 `USER_WORLD_INTEGRATION.md`，轉換與來源雜湊見 `RUNTIME_TRANSFORMS.json`。原貌旋轉檢視入口為 `/?world-model-review`。若更新這裡的模型，需要重新產生並驗證執行副本。
