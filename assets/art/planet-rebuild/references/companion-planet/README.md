# 同頻星球：建模能力驗證參考圖

請將使用者提供的完整主星灰模設計原圖放在此處，保留原始解析度與全部多視圖／特寫：

`assets/art/planet-rebuild/references/companion-planet/同頻星球.png`

目前尚未取得該原始 PNG。對話中能檢視的圖片、早期企畫圖與先前產生的渲染，不替代這份正式原圖；使用者的 Windows 本機路徑不能由雲端直接讀取。

原圖取得後，先核對內容、尺寸並記錄 SHA-256，再製作三個獨立 Blender 灰模試件：

1. 巨樹與樹屋：連續樹根、自然分枝、立體樹冠、樹洞入口、階梯。
2. 分層懸浮島體：不規則岩層、高低地形、懸挑、下層平台、瀑布落差。
3. 天文台：完整圓頂、拱柱、階梯、望遠鏡、建築細節。

每個試件獨立交付 `.blend`、`.glb`、45 度／正面／側面／背面灰模渲染、原圖裁切與渲染的並排比較，以及建模方法與未達成細節。

取得原圖之前不開始建模。三件交由使用者確認前，不製作整島、不做材質或動畫、不替換網站資產。Blender 能執行與 GLB 能載入，不視為造型品質通過。

既有程序化原型未獲核准，不得當成試件成果。若無法做到參考品質，需報告具體限制並提出可執行的雕刻、拓樸製作或具來源／授權的外部資產流程。
