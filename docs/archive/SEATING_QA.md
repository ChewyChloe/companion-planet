# 角色尺寸、坐姿與更濃的果凍材質

## 改動

- 星球場景的角色統一放大為 1.18 倍；保留各自比例和核准的 GLB 原始頂點。抓取／對話定位高度同步放大。
- 原坐姿只抬起腹部中央，未支撐整個腳底。現在以角色座標產生只用於坐姿的連續底部支撐，並重算該形變的法線；站立原始幾何完全不改。
- 椅面加寬、加深；椅背後移、書桌前移，地形整平區依新家具占地擴大。角色坐姿減少前傾，對齊水平椅面。
- 入座以抬升弧線過渡，支撐高度不再因垂直插值落後而低於目標高度。
- 再降低所有角色的桌面透射；水球仔從 0.80（先前版）經 0.55 試看後改為 0.32，增加厚度及吸收。星雲仔 B 改為 0.40。手機薄殼 opacity 水球仔 0.91、極光仔 0.94、蓬蓬仔 0.98、其餘 0.96，星雲仔 B 0.93；保留內部細節。

## 驗證方法

`check-seated-residents.mjs` 透過真正 UI 選角並開始專注。抵達椅子並進入閱讀姿勢後，逐頂點計算實際 morph + skin 變形，再轉到椅面、椅背、桌板的局部座標。若任何頂點進入縮小 4 mm 的家具包圍盒，即判定測試失敗；截圖提供主觀檢查。包圍盒量測能捕捉明顯穿入，不能取代所有三角形接觸或動畫每一幀的連續碰撞檢查。

`check-seat-arrival.mjs` 使用水球仔，桌面與觸控手機實際從地面走向椅子，每兩個渲染幀抽樣身體頂點，檢查途中家具穿入，並記錄實際材質與 1.18 倍尺寸。抽樣不是每個三角形／每一幀的物理保證。

`npm run check`：45 個單元／整合測試、型別、lint、正式建置及依賴檢查通過。包含九隻核准 Body POSITION hash 未變的檢查。既有動畫轉換有限性與場地家具落地測試保留，閱讀前傾斷言依新姿勢調整。

證據：artifacts/seating。外觀自然度與較濃材質仍待使用者確認；Render 部署及真實手機 GPU 效能未驗證。

最終結果：九隻初輪完整坐姿頂點量測均無穿入。入座抽樣首次抓到轉身手臂掃到椅背，已進一步後移椅背並加深椅面；最新桌面 11 次與手機 10 次抽樣均無穿入，WebGL 無錯誤。九隻角色坐姿本身未再變動，原量測身體外框與最終椅面／椅背／桌板間距推算也均大於零，見 final-clearance.json。九宮格為後移椅背之前的支撐驗證，arrival-desktop/phone 為最終家具畫面。
