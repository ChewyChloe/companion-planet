# 同頻星球：多星球、丘面與柔光材質

本輪以對話中提供的目標圖為依據。產品名稱一律為「同頻星球」；舊內部識別碼保留以相容既有本機資料，沒有把參考作品的星球名稱放進介面。

## 實作內容

- **地表**：以連續的橢球上半部與同一個 groundHeight 高度函數重建地形，保持書桌／休息區平整，周圍為向外下降的柔和丘面。外殼高度低於地表，避免碗狀高牆；沒有用遮罩掩蓋原有灰牆。行走半徑從 1.85 增為 4.15，圓形投影面積約為五倍，桌椅仍保留身體餘量。
- **行走**：抓起拖放、點空地走過去、自主散步都使用擴大的範圍。以桌面四角的可見性圖選路，避免走向桌子另一側時卡死。讀書／休息指令會維持到到達後，沒有為了趕測試而瞬移角色。
- **植栽與場景**：尖草改為批次圓頭植栽，集中成小片；樹冠改為連續的平滑擾動曲面。保留書桌、書本、休息墊，加入大型書本、花朵與各星球的地標。
- **天空與雲水**：實際 Shader 天空球、FogExp2、程序產生的柔邊雲霧 sprite、低對比度水波平面；不是靜態背景圖。環境採半球光、較低對比主光與暖金背光。
- **四個世界**：同頻星球、玫瑰花園、微風森林、月光書原。天空中的三顆目的地使用真正 3D Mesh / Raycaster 點擊；沒有黑色細框線。Hover 放大光暈並顯示名稱，也提供鍵盤可操作的名稱按鈕。旅行包含實際相機拉遠／靠近及霧氣過場。
- **檯燈**：燈罩／燈泡附近有實體 Raycaster 觸控區，Hover 顯示手勢。點擊後燈泡 emissive、暖色 PointLight 與環境光平順插值。另提供較好按的手機開關。各星球在本次使用期間保留獨立燈光與花朵狀態；旅行不改變計時器、聊天或選中的角色。
- **其他互動**：點書本讀書、點休息墊休息、點花或「澆花」讓花朵展開；仍保留角色拖放、點擊問候、九角色選擇與桌寵。

## 九種主體材質

材質設定集中於 src/art/companion-skin.ts。MeshPhysicalMaterial 搭配薄層散射／邊緣透光近似、程序粗糙度、微光與時間變化；這不是離線渲染器的體積 SSS。完整透射路徑在一般桌面 GPU 啟用，手機與 SwiftShader 使用較輕的半透明薄殼路徑。沒有把此降級宣稱為完全相同的折射效果。

| 角色 | 粗糙度 | 材質／動畫差異 |
|---|---:|---|
| 星雲仔 | 0.50 | 藍紫星雲的緩慢色變、微星點、觸角尖端微光 |
| 小星草 | 0.38 | 暖釉／珍珠光、浮動並呼吸發光的星星 |
| 蕨蕨子 | 0.30 | 玉石綠、頭頂蕨類擺動與金色孢子 |
| 菇菇獸 | 0.46 | 蠟質暖黃、發光菇帽與微細星粉 |
| 極光仔 | 0.20 | 較強偏光、流動青紫色、嫩葉微光 |
| 花苞寶 | 0.40 | 粉色磨砂透光、發光花心、較內收的待機手勢 |
| 星塵獸 | 0.32 | 深藍、金眼與星點、發光角與細星環 |
| 水球仔 | 0.10 | 清透冰藍、高品質路徑折射、泡泡紋與較明顯的水感晃動 |
| 蓬蓬仔 | 0.62 | 絲絨 sheen、暖色絨毛花蓬與緩慢飄動種子 |

內部星雲／星點以 Shader 近似；沒有宣稱完成真正的體積霧求解、皮下光傳輸或毛髮模擬。細節與參考圖的一致程度仍須看實際截圖判斷。

## 證據與重現

- artifacts/universe/test-report.json：整合各測試的最新結果，不重複計算重跑案例。
- artifacts/universe/visual-results.json：四世界畫面、狀態返回驗證、渲染錯誤與場景資料。
- artifacts/interaction/visual-results.json：九角色真實場景、材質數值與獨立透射路徑驗證。
- `node scripts/review-universe.mjs`：啟動 5173 開發服務後，擷取桌面／手機與各世界。`node scripts/review-companions.mjs`、`python3 scripts/compose-companions.py` 產生九角色比較圖（合成需 Pillow）。
- 初輪發現的灰碗保留於 before-bowl.png；修改後照片使用相同的互動場景實際 renderer 擷取，沒有換成預渲染插畫。

雲端使用 SwiftShader 軟體繪圖，場景的軟體算圖偏慢；已降低環境貼圖尺寸、批次植栽並採用薄殼材質，不以雲端的 FPS 宣稱實機效能已通過，也沒有為了通過測試而取消互動斷言。

近照會固定中性睜眼，以免眨眼影響材質／五官比較；星雲仔另提供正、側、背、45 度實際渲染。世界與角色近照採同一 renderer 暫停當前姿態並以 DPR 1 重繪，沒有以預渲染圖取代模型。報告中的軟體 FPS 來自正常自動降級執行，不能用靜態截圖的解析度推論效能。

觸控回歸也實際抓到書頁文字 LineSegments 預設命中容差過大的問題。裝飾線條／孢子已排除 Raycaster，角色阻擋點擊穿透；雙指與移動手勢會抑制合成 click。手機驗證保留原始 runner log、重跑 JSON，整合時只取同名案例的最後結果，沒有將失敗案例略過或重複加總。
