# 九隻角色：行進朝向、四肢與表情修正

## 修改範圍

保留九隻已核准模型的 Body POSITION、比例、頭飾和靜止五官位置，沒有重新生成 GLB。連續身體由蒙皮變形帶動四肢，不切開身體或加黏球形手腳。

- 依實際世界座標位移計算朝向，以最短角度轉身；停步保留最後朝向，閱讀時轉向書桌。
- 步幅依行進距離推進，左右腳交替前後擺動及小幅抬腳，手臂反向擺動，避免只有整體上下跳。移動改用有上限的固定速度，避免遠距離滑行。
- 材質測試網址恢復自主行為；只有明確的 `still` 參數才固定姿勢。
- 根據鏡頭相對朝向遮蔽背面五官，避免透射身體背後露出眼睛和嘴巴。側面保留近側眼睛。
- 新增開心彎眼、張嘴、傾聽微笑與瞇眼休息，搭配舉手／伸展。表情使用原本五官控制節點，隨轉身及身體動作移動。
- 九隻透射略降，保留內部星雲／星光／氣泡。星雲仔 B 的 transmission 從 0.72 降至 0.58；手機／桌寵薄殼 opacity 從 0.68 提至 0.80。其餘數值見 RESIDENT_MATERIALS.md。

## 驗證與證據

首次桌面回歸的兩項（安靜模式／AI 確認、離線與桌寵）通過。第一項所有功能斷言已執行完，但最後一張全場景截圖使整體超過原本 120 秒時限；trace 確認最後動作為 screenshot。將總時限調至 180 秒，功能斷言與單項等待時間不變，單獨重跑。原始失敗與通過紀錄保留於 web-initial-results.json。重跑第一項已通過（1.9 分鐘），見 web-retry-results.json；合計三項桌面回歸均已通過。

- `npm run check`：43 個測試通過，型別、lint、正式建置與依賴檢查通過。
- `scripts/review-resident-motion.mjs`：真正 R3F 渲染，九隻各兩個步態相位與背面，另含星雲仔五種表情。量測每隻四肢蒙皮頂點的加權中心位移，非僅檢查骨骼角度。
- `scripts/check-walking-direction.mjs`：正常網址與材質網址的實際去程／回程，朝向與實際位移一致、背面隱藏五官。
- 手機觸控回歸：390×844、實際 CDP touchStart/touchMove/touchEnd，蓬蓬仔抓起／拖曳／放下通過，角色位置改變且鏡頭未被誤旋轉；見 touch-results.json。
- 原始機器可讀結果與截圖：artifacts/motion-review。`pose-time` 僅供外觀頁重現特定相位；正式場景仍以實際距離及時間推進。
